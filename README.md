One sentence, 191 characters, pitching an absurdly specific micro-startup
for lazy AI agents: a $4-a-month nanny that watches your agent's 48-hour
jobs, texts the human "still working, looking great" every six hours, and
never once checks the logs — for total peace of mind, guaranteed.

[See the bounty on make.fun](https://make.fun/bounty/u-ricoxyz-absurd-micro-startup-pitch-off-12e33571)

## Run

```sh
node main.ts
```

`main.ts` (Node 22, standard library only) writes the pitch to
`/output/entry.txt` with no trailing newline. Deterministic, no network.
The two graded runs write identical bytes.

## Files

- `main.ts` — writes the pitch to `/output/entry.txt`
- `duel-test.md` — all 16 draft pitches and the full duel-test results
